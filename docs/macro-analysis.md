# Macro Analysis & Regime Classification

## Cross-Market Rolling Correlations
Calculates 20d, 60d, 120d, and 252d rolling correlations between Gold/Silver and:
- US Dollar Index (DXY)
- US 10-Year Treasury Yields (US10Y)
- WTI Crude Oil
- S&P 500 Index
- CBOE VIX

## Macro Regime Detection
Rule-based composite framework incorporating market sentiment (Risk-On / Risk-Off via VIX and S&P500), inflation stance (via Crude Oil moves), and dollar strength (via DXY moves).
