# Macro Analysis & Regime Detection

Evaluates macro drivers including USD Index (DXY), US 10Y Yields, Real Yields (TIPS), Crude Oil, Equity Volatility (VIX), and Equity market returns.
Classifies macro state into one of:
* Inflationary
* Disinflationary
* Deflationary
* Risk-On
* Risk-Off
* Tightening
* Easing
* Stagflationary
* Neutral
