# Model Evaluation & Forecast Performance Tracking

To ensure continuous model improvement and transparency, all forecasts generated by the pipeline are logged and evaluated as actual market outcomes materialize over time.

## Prediction Database Schema (`data/predictions/prediction_history.parquet`)

On date $T$, every forecast is stored with:
- `prediction_date`: Date $T$
- `instrument`: Instrument symbol
- `horizon`: Horizon in trading days (1, 3, 5, 10, 20, 60)
- `predicted_direction`: `UP` or `DOWN`
- `predicted_return`: Expected return (%)
- `confidence`: Confidence score (0-100)
- `actual_return`: Realized return at $T + \text{horizon}$ (populated when date $T + \text{horizon}$ arrives)
- `prediction_correct`: Binary indicator (1 if directional prediction matched actual outcome, else 0)

## Performance Tracking Metrics

The system monitors and records in `data/models/model-performance.json`:
- Overall Directional Accuracy (%)
- Directional Accuracy by Horizon
- Directional Accuracy by Market Regime
- MAE / RMSE on Return Predictions
