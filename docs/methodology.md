# Research Methodology

The pipeline follows a probabilistic research approach rather than deterministic claims:
1. All predictions are expressed as historical conditional statistics (e.g., "Historical analogues under similar conditions produced positive returns 64% of the time").
2. Explicit look-ahead bias protection: Features at date T only utilize data available up to date T.
3. Multi-factor analysis combining technical indicators, macro drivers, relative value ratios, and historical pattern matching.
