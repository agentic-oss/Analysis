# Methodology & Analysis Framework

## Analysis Pipeline Methodology

1. **Unit & Currency Standardisation**:
   - Gold Spot: USD/oz
   - Gold Domestic India: INR/10g
   - Silver Spot: USD/oz
   - Silver Domestic India: INR/kg
   - Conversion Formula: $\text{Price}_{\text{INR/10g}} = (\text{Price}_{\text{USD/oz}} \times \text{USDINR}) / 31.1034768 \times 10$

2. **Technical & Price Structure Signals**:
   - SMA / EMA crossovers (Golden Cross, Death Cross)
   - RSI 14 overbought/oversold boundaries
   - MACD momentum histogram trends
   - 20-day high/low breakout and breakdown detection

3. **Macro Drivers**:
   - Multi-factor classification analyzing interest rates, oil, DXY, and equity volatility.
