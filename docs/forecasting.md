# Forecasting & Historical Analogue Engine

## Historical Analogue Engine
Searches historical dataset for market states most similar to current state using weighted Euclidean distance across normalized technical and macro features.
Calculates forward probability distributions for 1d, 3d, 5d, 10d, 20d, 60d horizons.

## Predictive Models
- Baseline Conditional Historical Probability
- Logistic Regression (Direction)
- Random Forest (Direction)
- Ridge Regressor (Forward Return)
