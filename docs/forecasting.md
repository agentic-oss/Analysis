# Forecasting Framework

## Probabilistic Forecasting & Historical Analogue Philosophy

- **Zero Guarantees**: All forecasting outputs are strictly framed as probabilistic research signals.
- **Look-Ahead Bias Prevention**: Feature matrix at date T contains strictly information available by date T. Targets are computed for date $T + h$ and stored separately.
- **Analogue Similarity**: Computes Euclidean distance on standardized multi-factor vectors (RSI, MACD, Volatility, Distance from SMAs, Gold/Silver Ratio Z-score, DXY 20d return, US 10Y 20d change).
