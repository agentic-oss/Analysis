# Technical Analysis

## Indicators Calculated
- **Moving Averages**: SMA (5, 10, 20, 50, 100, 200), EMA (9, 20, 50, 200)
- **Momentum**: RSI 14, Stochastic RSI, MACD (12,26,9), MACD Signal, MACD Histogram, ROC 10, Momentum 10
- **Volatility**: ATR 14, Annualized Rolling Volatility (20d, 60d, 120d, 252d), Bollinger Bands (20d, 2.0 std), BB Width
- **Volume**: Volume SMA 20, Relative Volume, Volume Change, OBV
- **Price Structure**: Distance from 20/50/200 DMA, Distance from 52-week High/Low, Intraday Range, Gap %
- **Signals**: Golden Cross, Death Cross, 20-day Breakout/Breakdown, Volatility Expansion/Contraction
