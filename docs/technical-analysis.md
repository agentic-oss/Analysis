# Technical Analysis Specification

## Calculated Technical Metrics
- **Simple Moving Averages (SMA):** 5, 10, 20, 50, 100, 200 periods.
- **Exponential Moving Averages (EMA):** 9, 20, 50, 200 periods.
- **Relative Strength Index (RSI 14):** Wilder's smoothed RSI and Stochastic RSI.
- **Moving Average Convergence Divergence (MACD):** 12/26/9 EMA configuration.
- **Volatility & ATR:** Average True Range (14-day) and 20-day annualized historical log volatility.
- **Bollinger Bands:** 20-day SMA +/- 2 standard deviations.
- **Distance Metrics:** Percentage distance to SMA 20, 50, 200, and 52-week highs/lows.
