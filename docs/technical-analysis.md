# Technical Analysis Methodology

Computes standard indicators across all series:
* **Moving Averages**: SMA 5, 10, 20, 50, 100, 200 and EMA 9, 20, 50, 200.
* **Momentum**: RSI 14, Stochastic RSI (14, 3, 3), MACD (12, 26, 9), 10-day Rate of Change (ROC).
* **Volatility**: ATR 14, 20-day annualized historical volatility, Bollinger Bands (20, 2.0).
* **Price Structure**: Distance from 20/50/200 DMAs, distance from 52-week high/low, Golden/Death cross detection.
