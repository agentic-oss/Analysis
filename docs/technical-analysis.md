# Technical Analysis Methodology

Documentation of calculated indicators:
- **Moving Averages:** SMA (5, 10, 20, 50, 100, 200) and EMA (9, 20, 50, 200).
- **Momentum:** RSI 14, Stochastic RSI, MACD (12, 26, 9), Rate of Change (10d), Momentum (10d).
- **Volatility:** ATR 14, 20d/60d Historical Volatility, Bollinger Bands (20, 2).
- **Volume:** Relative Volume, Volume Change, On-Balance Volume (OBV).
- **Price Structure:** Distance from 20/50/200 DMA, 52-week High/Low distance, Gap, Intraday Range.
- **Pattern Detection:** Golden Cross, Death Cross, 20d Breakouts/Breakdowns, Volatility Expansion/Contraction.
