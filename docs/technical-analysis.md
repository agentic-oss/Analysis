# Technical Analysis Methodology

## Calculated Indicators
- **Simple Moving Averages (SMA)**: 5, 10, 20, 50, 100, 200 days
- **Exponential Moving Averages (EMA)**: 9, 20, 50, 200 days
- **Relative Strength Index (RSI)**: 14-period standard RSI and Stochastic RSI
- **MACD**: Fast=12, Slow=26, Signal=9
- **Average True Range (ATR)**: 14-period volatility metric
- **Historical Volatility**: 20-day annualized standard deviation of returns
- **Bollinger Bands**: 20-period moving average $\pm 2 \sigma$
- **Volume & OBV**: Volume SMA 20, relative volume, On-Balance Volume
- **Price Structure**: Distances from MAs, 52-week highs/lows, intraday range %, gap %, golden/death cross detection, and 20-day breakout/breakdown conditions.
