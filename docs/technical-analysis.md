# Technical Analysis Specifications

The platform calculates:

- **Moving Averages**: SMA (5, 10, 20, 50, 100, 200), EMA (9, 20, 50, 200).
- **Momentum**: RSI 14, Stochastic RSI, MACD (12, 26, 9), Rate of Change (10d).
- **Volatility**: ATR 14, 20-day annualized volatility, Bollinger Bands (20, 2.0) and Band Width.
- **Volume**: Volume SMA 20, Relative Volume, On-Balance Volume (OBV).
- **Structure**: Distance to 20/50/200 SMAs, 52-week High/Low distances, Gaps, Intraday Range, Trend Strength.
- **Signals**: Golden Cross, Death Cross, 20-day Breakout/Breakdown.
