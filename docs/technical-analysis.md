# Technical Analysis

Calculates standard technical indicators for precious metals:
- **Moving Averages**: SMA (5, 10, 20, 50, 100, 200), EMA (9, 20, 50, 200).
- **Momentum**: RSI 14, Stochastic RSI, MACD (12, 26, 9), Rate of Change (ROC 12), Momentum 10.
- **Volatility**: ATR 14, Historical Volatility 20d (annualized), Bollinger Bands (20, 2).
- **Volume**: Volume SMA 20, Relative Volume, OBV.
- **Structure**: Distance from SMAs, 52-week High/Low distance, Golden Cross, Death Cross.
