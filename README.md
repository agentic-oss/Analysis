# Gold & Silver Market Data, Analysis, and Forecasting Pipeline

A production-grade precious-metals research pipeline that continuously ingests market data, calculates multi-factor technical indicators, evaluates macro relationships, detects market/macro regimes, searches historical analogues without look-ahead bias, generates probabilistic forward-looking research signals, and manages an ML feature store.

> **Disclaimer:** All price predictions, forward probabilities, and forecasting outputs generated by this system are strictly probabilistic research signals and conditional historical statistics. They do not constitute guaranteed future prices or financial advice.

---

## Key Features

1. **Multi-Asset Ingestion & Provider Replacement**: Ingests Gold (Spot/Futures), Silver (Spot/Futures), Indian domestic markets (MCX ETF proxies), USD/INR, DXY, US Yields (10Y, 2Y, TIP real yields), Commodities (Brent, WTI crude, Copper), Equities (S&P 500, NIFTY 50), and Volatility (VIX, India VIX) via flexible `MarketDataProvider` interfaces.
2. **Indian Market Customization**: First-class support for INR measurements (INR/10g for gold, INR/kg for silver) alongside original USD prices, with exact exchange rate and conversion metadata tracking.
3. **Data Quality & Validation**: Comprehensive OHLC integrity checks, abnormal jump classification, duplicate timestamp detection, and daily structured JSON quality reporting (`data/quality/YYYY-MM-DD.json`).
4. **Technical & Relative Value Analysis**: Computes MAs, RSI, Stoch RSI, MACD, ATR, Bollinger Bands, OBV, 52-week distances, trend strength, and Gold/Silver ratio Z-scores, percentiles, and return spreads.
5. **Macro & Market Regime Classification**: Transparent, explainable rule-based macro regime detection (Inflationary, Disinflationary, Deflationary, Risk-On/Off, Tightening/Easing, Stagflationary) and trend/volatility market regimes.
6. **Historical Analogue Search Engine**: Multi-factor similarity search over historical states to estimate forward return distributions (1D, 3D, 5D, 10D, 20D, 60D) without temporal look-ahead leakage.
7. **ML Feature Store & Target Store**: Automated daily feature store creation preserving historical integrity and generating future target variables.
8. **Transparent Scoring System**: Composite 0-100 score built from sub-scores (Technical, Macro, Momentum, Volatility, Relative Value, Analogue, Model).
9. **Backtesting & Evaluation**: Walk-forward time-series model validation, trading backtest engine with transaction costs/slippage, and forecast outcome tracking against actual market results.
10. **Automated Daily Reporting & CI/CD**: Daily Markdown research reports (`reports/daily/YYYY-MM-DD.md`), machine-readable daily analysis (`data/analysis/daily/YYYY-MM-DD.json`), alert detection (`data/analysis/alerts/YYYY-MM-DD.json`), and automated GitHub Actions workflow (`.github/workflows/daily-metals-analysis.yml`).

```
├── data/
│   ├── raw/                 # Unmodified downloaded observations partitioned by date
│   ├── processed/           # Validated and indicator-enriched datasets
│   ├── features/            # ML-ready daily feature store
│   ├── quality/             # Daily data quality JSON reports
│   ├── analysis/            # Machine-readable daily research output & alerts JSON
│   └── models/              # Model performance tracking
├── reports/
│   └── daily/               # Daily Markdown research reports
├── src/
│   ├── ingestion/           # Market data providers & retries
│   ├── validation/          # Data quality rules & checks
│   ├── storage/             # Parquet storage manager & currency conversions
│   ├── indicators/         # Technical analysis indicators
│   ├── macro/              # Cross-market rolling correlation engine
│   ├── ratios/             # Gold/Silver ratio relative value metrics
│   ├── regimes/            # Rule-based macro and market regime classifiers
│   ├── patterns/           # Historical analogue similarity search engine
│   ├── forecasting/        # Probabilistic forward return statistics
│   ├── features/           # ML feature store builder
│   ├── scoring/            # Transparent multi-factor scoring
│   ├── models/             # Baseline forecasting models & walk-forward validation
│   ├── backtesting/        # Reusable backtesting engine
│   ├── evaluation/         # Forecast performance tracker
│   ├── reporting/          # Daily Markdown report & alert generator
│   └── pipeline/           # End-to-end execution runner
├── tests/                   # Automated pytest suite
└── docs/                    # Architectural & methodological documentation
```

## Quickstart

### 1. Installation

```bash
pip install pandas numpy scikit-learn pyyaml pyarrow yfinance pytest
```

### 2. Run Daily Pipeline

Execute the full daily pipeline for a specific date (e.g. `2025-01-15`):

```bash
PYTHONPATH=. python3 src/pipeline/runner.py 2025-01-15
```

For offline or test execution with synthetic data:

```bash
PYTHONPATH=. python3 src/pipeline/runner.py 2025-01-15 --mock
```

### 3. Run Automated Tests

```bash
PYTHONPATH=. pytest tests/
```
