# Gold & Silver Market Data, Deep Analysis, Historical Research, and Forecasting Pipeline

A production-quality precious metals market intelligence database, quantitative analysis pipeline, historical research engine, and probabilistic forecasting platform built for Gold & Silver research with an Indian-market focus.

## 🚀 Key Features

1. **Multi-Asset Ingestion & Conversion**: Automatically collects Spot Gold, Spot Silver, COMEX Futures, Indian Retail Gold/Silver proxies (INR/10g, INR/kg), USD/INR, DXY, US Treasuries (2Y, 10Y), Crude Oil, S&P 500, NIFTY 50, VIX, and India VIX.
2. **Batch QA Validation**: Validates OHLC bounds, duplicates, zero/negative prices, price jumps, and volume anomalies, outputting data quality logs to `data/quality/YYYY-MM-DD.json`.
3. **Full Technical Indicator Suite**: Moving averages (SMA 5-200, EMA 9-200), RSI, Stoch RSI, MACD, ATR, Bollinger Bands, Volume SMAs, OBV, structural distances, and pattern signals.
4. **Gold/Silver Relative Value**: Gold/Silver ratio, Z-scores, historical percentiles, mean-reversion signals, and relative forward returns.
5. **Macro & Market Regime Classification**: Transparent, rule-based macro regime detection (Inflationary, Disinflationary, Risk-On, Risk-Off, Stagflationary, Tightening, Easing) and independent market regimes for Gold and Silver.
6. **Historical Analogue Engine**: State vector pattern matching on historical dataset to evaluate forward 1D, 3D, 5D, 10D, 20D, and 60D return statistics.
7. **Probabilistic Forward Research Signals**: Multi-horizon probabilistic estimates framed strictly as conditional research signals rather than guaranteed future prices.
8. **ML Feature Store & Baseline Models**: ML-ready daily feature store with look-ahead bias protection, macro event features, and walk-forward validated baseline models.
9. **Forecast Evaluation Database**: Logs forecasts on date T and tracks actual realized outcomes at T + horizon in `data/predictions/prediction_history.parquet`.
10. **Signal Backtesting Engine**: Reusable strategy backtester accounting for transaction costs, slippage, and position sizing.
11. **Automated Reports**: Generates daily Markdown reports (`reports/daily/YYYY-MM-DD.md`) and structured JSON files (`data/analysis/daily/YYYY-MM-DD.json`).
12. **GitHub Actions Automation**: Workflows for automated daily execution, testing, secret protection verification, and automated git commits.

## ⚙️ Quickstart Guide

### 1. Installation
```bash
pip install -r requirements.txt
```

### 2. Run Tests
```bash
PYTHONPATH=. pytest
```

### 3. Execute Daily Pipeline
```bash
PYTHONPATH=. python3 src/pipeline/runner.py 2026-09-08
```
