# Precious Metals Market Data, Research, Deep Analysis, and Forecasting Pipeline

A production-quality precious metals market data ingestion, quantitative technical analysis, macroeconomic regime classification, historical analogue search, and probabilistic signal generation pipeline focused on Gold and Silver (USD & Indian INR markets).

## ⚠️ Important Disclaimer
All price forecasts, direction probabilities, and expected return statistics generated by this system are strictly framed as **probabilistic historical research signals** based on conditional statistical distributions. This platform does not guarantee future prices or outcomes.

---

## System Architecture Overview

```
src/
├── ingestion/       # MarketDataProvider & YahooFinanceProvider (with synthetic fallback)
├── validation/      # DataValidator (OHLC, timestamp, jump check, quality report)
├── storage/         # StorageManager (Parquet, CSV, JSON persistence with deduplication)
├── indicators/      # TechnicalIndicators (SMA, EMA, RSI, Stoch RSI, MACD, ATR, Volatility, BB)
├── metals/          # MetalAnalyzer (Gold/Silver technical structure & multi-period correlations)
├── ratios/          # RelativeValueAnalyzer (Gold/Silver ratio, percentiles, Z-score)
├── macro/           # MacroRegimeClassifier (Multi-factor Macro Regime engine)
├── regimes/         # MarketRegimeClassifier (Gold & Silver Trend/Volatility classification)
├── patterns/        # HistoricalAnalogueEngine (Look-ahead free multi-factor similarity engine)
├── forecasting/     # ForwardProbabilityEngine (Probabilistic signals & confidence scores)
├── features/        # FeatureStoreGenerator (ML-ready daily feature store generation)
├── models/          # MetalsForecastingModels (Time-series walk-forward ML models)
├── backtesting/     # BacktestEngine (Strategy backtester with transaction costs & slippage)
├── evaluation/      # ForecastEvaluator (Model performance & forecast drift tracking)
├── scoring/         # CompositeScorer & AlertDetector (Sub-scores & alert triggers)
├── reporting/       # ReportGenerator (Daily Markdown & Schema JSON generator)
└── pipeline/        # DailyMetalsPipeline (End-to-end orchestrator runner)
```

## Key Features

1. **Continuous Precious Metals & Macro Ingestion:**
   - Gold & Silver Spot / Futures (USD/oz).
   - Indian Gold & Silver Benchmarks (`GOLDBEES.NS`, `SILVERBEES.NS`, INR/10g, INR/kg).
   - Macro drivers: USD/INR, DXY, US10Y, US2Y, Crude Oil, Brent, S&P 500, NIFTY 50, VIX, India VIX.

2. **Data Validation & Quality Assurance:**
   - Classifies incoming records as `valid`, `suspicious`, or `invalid`.
   - Generates data quality reports in `data/quality/YYYY-MM-DD.json`.

3. **Multi-Factor Quantitative Research:**
   - 10 Moving Averages (SMA 5..200, EMA 9..200).
   - RSI 14, Stochastic RSI, MACD, ATR, Historical Volatility, Bollinger Bands, OBV.
   - Gold/Silver Ratio: 252-day Z-score, historical percentile rank, mean-reversion signals.
   - Multi-period rolling cross-asset correlations (20, 60, 120, 252 days).

4. **Historical Analogue Engine & Forward Probabilities:**
   - Multi-dimensional similarity scoring comparing current technical and macro vectors against historical observations without look-ahead bias.
   - Forward 1D, 3D, 5D, 10D, 20D, and 60D return distributions, directional probabilities, and explainable confidence scores.

5. **ML Feature Store & Backtesting:**
   - Generates daily feature matrices stored in Parquet format.
   - Reusable strategy backtesting engine with realistic costs, slippage, Sharpe, Sortino, and drawdown metrics.
   - Model tracking comparing date T forecasts against subsequent actual outcomes saved in `data/models/model-performance.json`.

6. **Daily Reports & Alerts:**
   - Generates Markdown research report (`reports/daily/YYYY-MM-DD.md`).
   - Generates schema-compliant JSON analysis report (`data/analysis/daily/YYYY-MM-DD.json`).
   - Generates alert logs (`data/analysis/alerts/YYYY-MM-DD.json`).

## Quick Start

### Installation

```bash
pip install pandas numpy scikit-learn pyyaml pyarrow yfinance pytest
```

### Running Tests

```bash
PYTHONPATH=. pytest
```

### Executing the Daily Pipeline

```bash
# Run for current date
PYTHONPATH=. python3 src/pipeline/runner.py

# Run for a specific historical date
PYTHONPATH=. python3 src/pipeline/runner.py 2024-01-15
```
