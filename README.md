# Precious Metals Market Intelligence Pipeline

A production-quality **Gold & Silver Market Data, Deep Analysis, Historical Research, and Forecasting Pipeline**.

The system continuously collects precious-metals market data, performs deep multi-factor analysis, generates daily research reports, builds an ML-ready historical feature store, evaluates historical analogues, and creates probabilistic forward-looking research signals.

> **Disclaimer**: All price predictions and forecasting outputs generated by this system are strictly framed as **probabilistic research signals** derived from historical conditional statistics. They do NOT represent guaranteed future market prices or financial advice.

---

## Key Features

1. **Multi-Asset Ingestion**: Ingests Gold Spot, Silver Spot, Gold/Silver Futures, USD/INR FX, DXY, US 10Y/2Y Yields, Crude Oil, S&P 500, NIFTY 50, VIX, India VIX, and macro economic events.
2. **Indian Market Focus**: Native support for Indian measurements (`INR/10g` for Gold, `INR/kg` for Silver) stored as first-class datasets alongside exact exchange rates and conversion timestamps.
3. **Data Quality & Validation**: Automated validation classifying records as `valid`, `suspicious`, or `invalid` with checks for missing timestamps, zero prices, invalid OHLC relationships, and extreme price jumps.
4. **Technical Analysis**: Comprehensive indicator suite including MAs (SMA/EMA), RSI, Stochastic RSI, MACD, ATR, Historical Volatility, Bollinger Bands, OBV, and technical breakout triggers.
5. **Gold/Silver Relative-Value Analysis**: Gold/Silver ratio z-scores, rolling return spreads, historical percentiles, and forward return distributions following extreme ratio levels.
6. **Cross-Market Correlations & Regimes**: Multi-window rolling correlations (20D to 252D) and explainable Macro Regime detection (Inflationary, Risk-On, Risk-Off, Tightening, Easing, Stagflationary).
7. **Historical Analogue Engine**: Look-ahead-bias-free search for historical market states similar to today's state, providing conditional forward return distributions (1D to 60D).
8. **ML Feature Store & Forecasting Models**: Daily feature store generation with separate future targets, baseline ML models (Linear/Logistic Regression, Random Forest, Gradient Boosting), and walk-forward validation.
9. **Forecast Performance Tracking**: Persistent tracking comparing predictions on date T against subsequent actual outcomes.
10. **Backtesting & Transparent Scoring**: Modular backtesting with realistic transaction costs/slippage, transparent composite scores (0-100), confidence scoring, and configurable alert triggers.
11. **Automated Daily Reporting**: Generates structured JSON (`data/analysis/daily/YYYY-MM-DD.json`) and Markdown research reports (`reports/daily/YYYY-MM-DD.md`).
12. **GitHub Actions Automation**: Automated daily pipeline execution, testing, and secret protection checks.

## Quick Start

### Installation

```bash
# Clone the repository
git clone https://github.com/your-repo/precious-metals-pipeline.git
cd precious-metals-pipeline

# Install dependencies
pip install pandas numpy scikit-learn pyyaml pyarrow yfinance pytest
```

### Running the Daily Pipeline

```bash
# Run pipeline for today's date
PYTHONPATH=. python3 src/pipeline/runner.py

# Run pipeline for a specific historical date
PYTHONPATH=. python3 src/pipeline/runner.py 2026-03-31
```

### Running Automated Tests

```bash
pytest
```

│   └── quality/              # Daily data quality reports

│   ├── metals/               # Gold & Silver analyzers
│   ├── ratios/               # Gold/Silver ratio analyzer

│   ├── regimes/              # Macro & market regime detectors

│   ├── features/             # Daily feature store generator
│   ├── forecasting/          # Probabilistic forward return engine
