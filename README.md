# Precious Metals Research, Deep Analysis, and Forecasting Pipeline

A production-quality **Gold & Silver Market Data, Deep Analysis, Historical Research, and Forecasting System**.

The system continuously collects precious-metals market data, performs deep multi-factor analysis, generates daily Markdown research reports, builds ML-ready feature stores, evaluates historical patterns without look-ahead bias, tracks prediction accuracy over time, and creates probabilistic forward-looking research signals.

---

## Key Features

- **Continuous Ingestion**: Supports Spot Gold, Spot Silver, Gold Futures, Silver Futures, Indian Gold (GOLDBEES), Indian Silver (SILVERBEES), USD/INR, DXY, US 10Y/2Y Yields, Crude Oil, S&P 500, NIFTY 50, VIX, and India VIX.
- **Indian Market Support**: Direct collection and unit-aware conversions (USD/oz to INR/10g and INR/kg) with exact exchange rates and timestamps logged.
- **Data Validation & Quality Tracking**: Batch validation classifying observations into `valid`, `suspicious`, or `invalid`, generating `data/quality/YYYY-MM-DD.json`.
- **Technical & Cross-Market Analytics**: Full technical suite (SMAs, EMAs, RSI, MACD, ATR, Bollinger, OBV, 52w high/low distances) and rolling 20/60/120/252-day cross-market correlations.
- **Gold/Silver Relative-Value Analytics**: Gold/Silver ratio, percentiles, Z-scores, spread volatility, and mean-reversion signals.
- **Regime Detection**: Transparent, rule-based Macro Regime framework and Market Regime classifiers for Gold & Silver.
- **Historical Analogue Engine**: Multi-factor similarity scoring matching today's market vector against historical states to calculate forward return statistics (1D, 3D, 5D, 10D, 20D, 60D) with zero look-ahead bias.
- **ML Baseline & Scoring Framework**: Walk-forward time-series validation with transparent 0–100 component scores, composite score, and confidence rationale.
- **Backtesting & Forecast Evaluation**: Strategy backtester accounting for costs/slippage and continuous prediction performance tracking stored in `data/models/model-performance.json`.
- **Automated Reporting & CI/CD**: Daily Markdown reports (`reports/daily/YYYY-MM-DD.md`), daily machine-readable JSON outputs (`data/analysis/daily/YYYY-MM-DD.json`), daily risk alerts (`data/analysis/alerts/YYYY-MM-DD.json`), and GitHub Actions workflow.

## Quick Start

### 1. Install Dependencies

```bash
pip install pandas numpy scikit-learn pyyaml pyarrow yfinance pytest
```

### 2. Run Daily Pipeline

```bash
PYTHONPATH=. python3 src/pipeline/runner.py 2026-03-01
```

### 3. Run Test Suite

```bash
pytest tests/
```
