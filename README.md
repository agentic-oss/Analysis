# Gold & Silver Market Data, Deep Analysis, Historical Research, and Forecasting Pipeline

A production-grade, continuous market intelligence and forecasting platform for precious metals with an Indian market focus.

## Key Features

- **Continuous Data Ingestion**: Collects daily OHLCV prices for Spot Gold, Spot Silver, Gold Futures, Silver Futures, USD/INR, DXY, US 10Y/2Y Yields, Crude Oil, S&P 500, NIFTY 50, VIX, and India VIX.
- **Indian Market Focus**: First-class support for Indian measurements (INR/10g gold, INR/kg silver, USD/INR rate recording).
- **Data Quality & Validation**: Automated batch validation classifying data into `valid`, `suspicious`, and `invalid` with JSON quality reports.
- **Technical Analysis**: Complete suite of indicators (SMAs, EMAs, RSI, Stochastic RSI, MACD, ATR, Historical Volatility, Bollinger Bands, OBV, distances to MAs/52w extremes, Golden/Death Cross, Breakouts/Breakdowns).
- **Asset & Relative-Value Analysis**: Gold/Silver ratio metrics (percentile, Z-score, mean reversion, spread volatility) and cross-market correlation tracking across 20d, 60d, 120d, and 252d windows.
- **Explainable Regime Detection**: Rule-based macro regime model (Inflationary, Disinflationary, Risk-On, Risk-Off, Tightening, Easing, Stagflationary, Neutral) and asset trend/volatility regimes.
- **Historical Analogue Engine**: Searches historical database for multi-factor matching market conditions and calculates forward return distributions (1D, 3D, 5D, 10D, 20D, 60D) without look-ahead bias.
- **ML Feature Store & Probabilistic Signals**: Daily leak-free feature store and baseline ML models (Logistic Regression, Random Forest, Gradient Boosting) generating probabilistic research signals.
- **Backtesting & Forecast Performance Tracking**: Event-driven strategy backtesting and continuous evaluation of past predictions against realized outcomes (`data/models/model-performance.json`).
- **Daily Automated Reports**: Human-readable Markdown research reports (`reports/daily/YYYY-MM-DD.md`) and machine-readable JSON payloads (`data/analysis/daily/YYYY-MM-DD.json`).

## Quick Start

### Installation

```bash
pip install pandas numpy scikit-learn pyyaml pyarrow yfinance pytest
```

### Running the Daily Pipeline

```bash
PYTHONPATH=. python3 src/pipeline/runner.py [YYYY-MM-DD]
```

### Running Tests

```bash
pytest tests/ -v
```
